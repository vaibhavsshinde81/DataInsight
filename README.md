# DataInsight

🚀 AI-Powered Data Analysis Platform

DataInsight is a web application that allows users to upload CSV or Excel datasets and ask questions in natural language. The application uses the Groq LLM to generate intelligent insights from the uploaded data.

## Features

- 📊 Upload CSV and Excel files
- 🤖 AI-powered data analysis using Groq LLM
- 📈 Automatic dataset preview
- 💬 Ask questions in natural language
- ⚡ Fast Flask web application

## Technologies Used

- Python
- Flask
- Pandas
- NumPy
- Groq API
- HTML
- CSS
- JavaScript

## Installation

```bash
git clone https://github.com/YOUR_USERNAME/DataInsight.git

cd DataInsight

pip install -r requirements.txt

python app.py
```
